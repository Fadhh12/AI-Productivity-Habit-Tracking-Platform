# Phase 45 — Mascot on login, register, onboarding, 404 and error

- Login and Register: Conti sits on top of the card (`AuthMascot`). It covers its eyes while the password field has focus, thinks while the request runs, and looks worried when the server answers with an error. Otherwise its eyes follow the pointer.
- Onboarding: a bigger Conti guides each step with a one-line hint and changes face (thinking while AI suggests habits, cheering on the last step, worried on an error).
- 404 and the error page: a worried Conti replaces the logo dot.
