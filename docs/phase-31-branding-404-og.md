# Phase 31 — Branded 404, error page and share preview

- `app/not-found.tsx` and `app/error.tsx`: friendly, on-brand dead ends with a way back (retry / home).
- `app/opengraph-image.tsx`: 1200x630 preview generated by `next/og` (no new dependency), used when the link is shared on WhatsApp, Instagram, X.
- `app/layout.tsx`: `metadataBase`, title template, icons and Open Graph / Twitter metadata. Set `NEXT_PUBLIC_SITE_URL` in production so preview URLs are absolute (defaults to `http://localhost:3001`).
