# Phase 38 — Mobile navigation: compact floating bar + "Lainnya" sheet

The old bottom bar listed all 8 destinations and scrolled sideways. Now:

- A floating pill with four everyday tabs (Beranda, Habit, Goals, Coach) plus a "Lainnya" button. Only the active tab shows its label, in a lime pill; the others are icon-only, so the bar stays short.
- "Lainnya" opens a bottom sheet (3-column tiles, staggered in) with Logs, Laporan, Lencana, Setelan, Continuum Plus and Akun. The button turns into an X while open; Escape and tapping the backdrop close it.
- Short labels renamed to plain Indonesian (Laporan, Lencana, Setelan). Toast position moved up to clear the bar.
